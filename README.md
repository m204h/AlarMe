# AlarMe
An open-source alternative to Alarmy and inspired by it.

you can visit my website in the setting to contact me, If you have any suggestions or to notify me for any bugs.


- Create one-time or repeating alarms.
- Choose a system sound or your own audio.
- Stop or snooze alarms when they ring.

For suggestions or bug reports, visit [my website](https://techmh.me).
